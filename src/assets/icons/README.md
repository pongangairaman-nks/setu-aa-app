# Icons Directory

This directory contains icon assets used in the Setu AA Mobile App.

## Structure

- `navigation/` - Navigation icons (home, accounts, transactions, etc.)
- `actions/` - Action icons (add, edit, delete, etc.)
- `status/` - Status icons (success, error, warning, etc.)
- `financial/` - Financial icons (bank, card, money, etc.)

## Usage

Import icons in your components:

```typescript
import homeIcon from '../assets/icons/navigation/home.png';
```

## Guidelines

- Use SVG format when possible for scalability
- Use PNG format for complex icons
- Maintain consistent size (24x24, 32x32, etc.)
- Use descriptive file names
- Follow the app's design system
