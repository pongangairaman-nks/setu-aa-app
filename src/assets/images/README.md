# Images Directory

This directory contains all image assets used in the Setu AA Mobile App.

## Structure

- `icons/` - App icons and small graphics
- `logos/` - Company and bank logos
- `backgrounds/` - Background images
- `placeholders/` - Placeholder images for loading states

## Usage

Import images in your components:

```typescript
import logo from '../assets/images/logos/setu-logo.png';
```

## Guidelines

- Use PNG format for icons and logos
- Use JPG format for photos and backgrounds
- Optimize images for mobile devices
- Keep file sizes under 500KB for better performance
- Use descriptive file names
